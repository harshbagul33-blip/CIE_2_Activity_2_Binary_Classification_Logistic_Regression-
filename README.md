# CIE_2_Activity_2_Binary_Classification_Logistic_Regression-
## Dataset Source

**Dataset Name:** Loan Prediction Dataset

**Dataset File:** `train.csv`

**Original Source:** Kaggle – Loan Eligibility Prediction

**Dataset Link:** https://www.kaggle.com/competitions/loan-eligibility-prediction/data

**GitHub Repository:** https://github.com/snehajangid/Loan_Prediction

### Dataset Description
The dataset contains information about loan applicants, including their education, income, employment status, credit history, loan amount, and property area.

### Input Features
- Dependents
- Education
- Self Employed
- Applicant Income
- Co-applicant Income
- Loan Amount
- Loan Amount Term
- Credit History
- Property Area

### Target Variable
`Loan_Status` – Y (Approved) or N (Not Approved).

### Objective
To predict whether a loan application will be approved or rejected using Logistic Regression.
