# CIE_2_Activity_2_Binary_Classification_Logistic_Regression-
Binary Classification using Logistic Regression
Objective: Build a Logistic Regression model to predict whether a loan application is approved or rejected using applicant and loan-related information.

Dataset: Loan Prediction Training Dataset (614 labelled applications).

Target variable: Loan_Status  
- Y = Approved (positive class, 1)
- N = Not Approved (0)
